<h1>Солодка майстерня</h1>
  <p>Це сучасний адаптивний вебсайт онлайн-магазину десертів, створений командою майбутніх розробників.  
Сайт дозволяє користувачам ознайомитись з асортиментом десертів, прочитати відгуки клієнтів та швидко перейти до покупки.</p>
